Each row is a pair of Sponsors that find_sponsor_merge_candidates suspects are the same organisation spelled two different ways — e.g. Universitair Medisch Centrum Groningen vs. Universitair Medisch Centrum. Nothing is merged automatically; every pair below is Pending until a human decides.

Basis explains why the pair was flagged:

  • Suffix variant — the names are identical once a trailing legal-entity suffix (Inc, Ltd, GmbH, AG, …) is stripped. Usually the same entity.
  • Containment — one name is a token-for-token prefix of the other (e.g. Aalborg University vs. Aalborg University Hospital). This catches genuine variants, but also related-but-distinct organisations — read both names carefully before deciding.

Select the rows you've reviewed and choose an action from the dropdown below:

  • Merge (into curated/larger) — combines the pair into a single Sponsor. The survivor is whichever side is manually curated, or otherwise whichever has more trials; the other side's trials are reassigned to it and its Sponsor record is deleted. This cannot be undone.
  • Dismiss — marks the pair as reviewed and not a match (e.g. two genuinely different organisations). Dismissed pairs are remembered and won't be suggested again.

The list defaults to showing only Pending pairs; use the Status filter to review pairs already decided.
